1. Project Abstract

Traditional ADAS systems monitor external road hazards rather than internal driver state. The Edge-AI Driver Monitoring System provides real-time, privacy-preserving behavioral monitoring running entirely on edge CPU hardware without cloud reliance. Integrating MediaPipe FaceMesh (478 pts), YOLOv8n (Nano), and a deterministic Safety Scoring Engine (100→0), the system triggers sub-millisecond offline bilingual voice alerts (English/Tamil) and provides automated driving coaching.

2. Problem Statement & Motivation
  • Driver-Centric Risk: Over 80% of road collisions stem from driver fatigue, microsleep, gaze diversion, and mobile phone usage.
  • Cloud Limitations: Cloud-based video streams cause high latency (300ms+), network dead-zones, and severe privacy violations.
  • Edge Paradigm: Need for a low-cost, edge-first embedded DMS capable of multi-violation detection under 150ms on standard CPUs.
3. Project Objectives
01 Track eye closure & microsleeps via EAR & 60s PERCLOS.

04 Maintain dynamic safety score with +3 pts / 5min recovery.

6. Core Vision Algorithms & Mathematical Formulations
A. Drowsiness (EAR & PERCLOS Metric):
$$\text{EAR} = \frac{\|p_2 - p_6\| + \|p_3 - p_5\|}{2 \cdot \|p_1 - p_4\|}$$ Threshold: $\text{EAR} < 0.21$ for $>1.5\text{s}$

Uses 6 canonical landmark coordinates per eye. A 20-frame rolling window filters normal blinks, while a 60-second sliding PERCLOS window tracks long-term cumulative fatigue.

B. Head Pose Distraction ($cv2.solvePnP$):
$$\mathbf{R}, \mathbf{t} = \text{solvePnP}(\mathbf{P}_{3D}, \mathbf{p}_{2D}, \mathbf{K}, \mathbf{D}) \xrightarrow{\text{RQDecomp}} (\text{Yaw}, \text{Pitch}, \text{Roll})$$ Envelope: $\pm 25^\circ \text{Yaw}, \pm 20^\circ \text{Pitch}$

Matches 6 2D facial landmarks (nose, chin, eye corners, mouth corners) to a 3D canonical face model to classify directional gaze (FORWARD, LEFT, RIGHT, DOWN).

10. Conclusion & Future Enhancements

Conclusion: Developed an end-to-end, edge-native Driver Monitoring System combining MediaPipe FaceMesh, YOLOv8n, and dynamic scoring. Delivered robust multi-violation detection at 5.43 FPS on standard edge CPUs with zero cloud latency and complete user privacy.

Future Enhancements:
  • OBD-II CAN Bus: Correlate steering angle, brake pressure, and vehicle speed with fatigue.
  • Hardware NPU: Deploy ONNX/TensorRT on Google Coral or Hailo-8 for 30+ FPS edge inference.
  • NIR Camera: Active near-infrared illumination for pitch-black nighttime cabin monitoring.
